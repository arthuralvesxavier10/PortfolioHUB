# MANUAL DO USUÁRIO — Sistema JOIN

## 1. Introdução
O sistema JOIN foi desenvolvido para integrar e agilizar o fluxo de informações internas, permitindo melhor comunicação entre setores técnicos e administrativos.

## 2. Objetivo
Orientar o usuário na navegação, utilização e entendimento das principais funcionalidades do sistema.

## 3. Acesso
O acesso é feito por navegador web (Google Chrome ou Edge).  
O usuário deve inserir seu login e senha cadastrados para autenticação.

## 4. Funcionalidades Principais
- **Painel Inicial:** exibe status de chamados e notificações recentes.
- **Chamados Técnicos:** registro de ocorrências e solicitações de manutenção.
- **Inventário de Equipamentos:** consulta rápida de computadores e impressoras cadastradas.
- **Relatórios:** geração de PDFs automáticos com base nos dados registrados.

## 5. Segurança
- Alterar a senha regularmente;
- Não compartilhar credenciais;
- Encerrar a sessão ao finalizar o uso.

## 6. Suporte
Em caso de dúvidas, contate o setor de TI responsável pela implantação.
